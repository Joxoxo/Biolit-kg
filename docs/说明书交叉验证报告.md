# BioLit-KG 说明书交叉验证报告

> 最后更新：2026-11-05 · 审核人：项目作者（药学背景）· 抽取模型：gemini-3.5-flash-lite
> 目的：用 FDA 药品说明书这一独立、权威的来源，核对文献图谱里的药物安全证据，区分"已知"和"仅文献报道（潜在信号）"。

## 一、结论

1. **被多篇文献重复报道的结论，与说明书高度一致。**至少 2 篇文献支持的 64 个项目中，不良反应（35 项）和药代（15 项）全部能在说明书中找到对应，可作为抽取方向正确的间接证据。
2. **发现 3 处说明书与文献的实质冲突**（人工确认），其中最典型的是：阿哌沙班说明书点名克拉霉素"无需调整剂量"，而 FAERS 研究显示合用时出血信号升高（ROR 1.60，95% CI 1.16–2.20）、药代研究显示暴露量升高到 1.38 倍。
3. **"仅文献报道"的相互作用与药代项中，61 项经人工确认说明书确实未提及**，集中在说明书更新滞后的几类：抗肿瘤靶向药、新型抗病毒药、抗菌药、心血管常用合并用药，以及药物基因组学 / 次要代谢途径。这些都是单篇文献报道，属于"值得关注的潜在信号"，不等于已确认的风险。
4. **说明书抽取同样会漏掉列举项**，和文献抽取的主要错误一致。用"在说明书原文中搜索"的兜底检查补回了 19 项。

## 二、方法

| 步骤 | 做法 |
|---|---|
| 1 下载说明书 | 从 openFDA 下载 7 种药的美国说明书；同一种药有多份时，优先原研品牌（Eliquis、Xarelto、Pradaxa、Savaysa、Plavix、Brilinta），华法林原研已停产，选最新的仿制药说明书 |
| 2 抽取 | 每种药分两次调用大模型：①黑框警告、禁忌、警告、不良反应；②相互作用、临床药理、警告。抽成 4 类：不良反应、禁忌、相互作用、药代。说明书按"药物类别"写的相互作用，括号里举例的药名逐个记录；"无需调整剂量"也记录。共 14 次调用、160 条 |
| 3 证据核验 | 复用文献抽取的证据核验程序：160 条中 148 条证据句与说明书原文逐字一致，12 条高度相似，0 条找不到 |
| 4 比对 | 文献图谱中，7 种药的（药物, 不良事件）、（药物, 合用药）、（药物, 酶或转运体）共 327 个项目，逐个查说明书。疗效比较类结论（如"相比华法林降低卒中"）说明书没有对应内容，不参与比对 |
| 5 人工审核 | "说明书不一致"和"仅文献报道"的相互作用与药代项（105 项），附文献证据句和说明书原文，由作者逐条判定 |

**比对规则**（依次判断）：

| 结果 | 含义 |
|---|---|
| 说明书已收录 | 说明书直接写了这一项（含类别后举例的药名） |
| 上位概念收录 | 说明书写的是更宽的概念：文献"消化道出血""BARC 2 型出血"等 → 说明书"出血" |
| 类别收录 | 合用药属于说明书写的药物类别，如泊沙康唑 → "P-gp 和强效 CYP3A4 联合抑制剂"。类别归属参考 FDA 公布的抑制剂 / 诱导剂示例名单 |
| 原文提及（抽取遗漏） | 大模型没抽出来，但在说明书原文中能搜到这个词（不调用大模型的兜底检查） |
| 说明书不一致 | 说明书明确写"无需调整剂量 / 无临床相关相互作用"，而文献报道了相互作用 |
| 仅文献报道 | 以上都不满足 |

## 三、结果

### 自动比对（327 个项目）

| 类别 | 说明书已收录 | 上位概念收录 | 类别收录 | 原文提及（抽取遗漏） | 说明书不一致 | 仅文献报道 | 合计 |
|---|---|---|---|---|---|---|---|
| 不良反应 | 9 | 103 | 0 | 7 | 0 | 32 | 151 |
| 相互作用 | 14 | 0 | 31 | 7 | 9 | 80 | 141 |
| 药代 | 14 | 0 | 0 | 5 | 0 | 16 | 35 |

至少 2 篇文献支持的 64 个项目：不良反应 35 项、药代 15 项全部在说明书中有对应；相互作用 14 项中有 2 项"说明书不一致"（阿哌沙班、利伐沙班与克拉霉素），其余均有对应。

### 人工审核（105 项：说明书不一致 9 + 仅文献报道 96）

| 自动比对结果 | 真信号（说明书确未涵盖） | 说明书其实有 | 抽取错误 |
|---|---|---|---|
| 说明书不一致（9） | 3 | 6 | 0 |
| 仅文献报道（96） | 61 | 30 | 5 |
| 合计（105） | 64（61%） | 36（34%） | 5（5%） |

- **自动比对的"仅文献报道"中，64% 经人工确认为真**。另外 31% 说明书其实有，主要是说明书用了笼统的类别表述，脚本没有对上。例如"启用或停用任何抗菌药物时密切监测 INR"涵盖了阿奇霉素、头孢氨苄；Paxlovid 含利托那韦，而说明书已点名利托那韦。
- **5 项抽取错误**：证据句只是研究目的陈述（"旨在评估……"），或原文结论是"相互作用风险低"却被抽成了相互作用，或把"在比伐芦定背景下比较替格瑞洛与氯吡格雷"误抽为替格瑞洛与比伐芦定相互作用。

### 说明书与文献的实质冲突（3 项）

| 药物 | 合用药 | 说明书 | 文献 |
|---|---|---|---|
| 阿哌沙班 | 克拉霉素 | 点名克拉霉素，称无需调整剂量 | FAERS 出血信号 ROR 1.60（PMID 36908021）；暴露量 GMR 1.38（PMID 36870039） |
| 依度沙班 | P-gp / CYP3A4 抑制剂 | 对 P-gp 抑制剂"不建议减量" | 队列研究：合用时大出血风险升高，aHR 1.24（PMID 37791408） |
| 依度沙班 | 环孢素 | 同上（笼统的"无需减量"） | 综述提示肾功能不全患者中相互作用更明显（PMID 42652049，证据级别有限） |

作为对照，利伐沙班与克拉霉素虽然也被脚本标为"不一致"，但审核认为一致：说明书明确写了"暴露变化不太可能影响出血风险"，而文献只有药代数据、没有出血结局。

### 说明书未涵盖的潜在信号（61 项，均为单篇文献）

| 类型 | 例子 |
|---|---|
| 抗肿瘤药 | 伊布替尼、厄洛替尼、哌柏西利、瑞波西利、阿美替尼、伏美替尼、塞瑞替尼、伊马替尼、舒尼替尼、特泊替尼、贝伐珠单抗（与阿哌沙班 / 利伐沙班 / 达比加群） |
| 抗菌 / 抗病毒药 | 氟喹诺酮类（环丙沙星、左氧氟沙星、莫西沙星）与达比加群；阿奇霉素、氟康唑与达比加群；阿兹夫定与利伐沙班、华法林 |
| 心血管合并用药 | ARB、ACEI、二氢吡啶类钙通道阻滞剂、洋地黄类、他汀类与阿哌沙班；胺碘酮类与依度沙班；替格瑞洛与 DOAC 合用（大出血 aHR 1.50） |
| 其他合并用药 | 环硅酸锆钠（与氯吡格雷、达比加群、华法林）；抑酸药与 DOAC（文献提示**降低**消化道出血，属保护性作用）；呋塞米与华法林；葡萄柚汁、白藜芦醇与替格瑞洛 |
| 药物基因组学 / 代谢途径 | 达比加群 CES1；利伐沙班 CYP3A5、OAT3；替格瑞洛的 UGT 葡萄糖醛酸化途径（7 个 UGT 亚型） |

## 四、局限性

1. **"真信号"指说明书未提及，不代表因果关系已确认。**全部为单篇文献，其中不少来自 FAERS 自发报告挖掘或 PBPK 模型预测，证据等级有限。
2. **只用了美国说明书。**中国说明书（NMPA 版本）的内容可能不同；美国说明书本身也有更新滞后。
3. **判定标准有弹性。**说明书对"抗菌药物""草药"等有笼统的监测提示时，审核中算作"说明书其实有"。如果改为"必须点名才算"，"真信号"会更多（审核备注中已标出这类边界情况，如阿帕他胺、大麻与华法林）。
4. **只审核了相互作用与药代。**不良反应的"仅文献报道"（32 项）多为零散事件（如一篇 FAERS 挖掘研究中的视力障碍、甲状腺疾病），未逐条审核。
5. **单人审核**，没有第二位审核者。

## 五、复现

```bash
python -m biolit.ingest.druglabel        # 下载 FDA 说明书（openFDA，不消耗大模型额度）
python -m biolit.label.extract           # 抽取说明书信息（14 次调用）
python -m biolit.label.compare           # 与文献图谱比对 → data/annotations/label_crosscheck.md
python -m biolit.label.compare review    # 生成人工审核表 → label_review_已审核.xlsx
```
