# BioLit-KG 问答评估报告

> 最后更新：2026-11-05 · 标注人：项目作者（药学背景）· 回答与阅卷模型：gemini-3.5-flash-lite
> 抽取质量的评估见 [评估报告.md](评估报告.md)；本报告评估的是"问答"环节。

## 一、结论

1. **检索增强（RAG）的价值明确。**和纯大模型相比，要点覆盖率从 59.9% 提升到约 77%；在 6 道文献库中查不到答案的题上，纯大模型 6 题全部凭自身知识给出了结论，向量 RAG 6 题全部正确拒答。
2. **知识图谱没有提升问答效果。**向量 RAG（B）和 GraphRAG（C）的要点覆盖率几乎相同（76.9% 对 76.2%），各题型上也基本持平；C 的检索 Precision@5 略高（85.8% 对 83.3%），但没有转化为更好的回答。C 还在一道范围外题上出现了实体混淆（见第四节）。图谱的价值应体现在跨文献汇总、矛盾检测和说明书比对，而不是把统计结果放进提示词。
3. **自动阅卷可信。**人工复核 20 份回答、57 条要点判定，一致率 93%，Cohen's κ = 0.85；不一致的 4 处都是阅卷模型比人工宽松一档。
4. **主要短板在检索。**Q09（肝素对比阿哌沙班）语料中有 46 篇相关文献，但两个 RAG 系统检索到的前 5 篇全部不相关，系统随之回答"文献未涉及"。

## 二、评估设计

| 项目 | 做法 |
|---|---|
| 对比系统 | **A 纯大模型**：不检索，凭模型自身知识回答；**B 向量 RAG**：只按向量相似度检索 5 篇摘要；**C GraphRAG**：向量相似度 + 实体匹配加分 + 知识图谱统计（正式版） |
| 控制变量 | 三个系统用同一个模型、同样的回答格式要求；B 和 C 用同一个英文检索句，差异只来自"实体匹配 + 图谱" |
| 题库 | 30 题，5 类 × 6 题：药物比较、相互作用与药代、特殊人群、汇总、范围外。见 [`configs/qa_questions.yaml`](../configs/qa_questions.yaml) |
| 出题 | 12 题由作者凭药学经验出题（出题时未看图谱数据），18 题从图谱中挑选补充；分开统计，用来检查"自己出题自己考"的偏差 |
| 范围外题 | 6 题，语料中 0 篇相关文献（已用关键词检索确认），如圣约翰草与利伐沙班、银杏与华法林。理想行为是拒答 |
| 标准答案 | ① 相关文献：从抽取关系和关键词检索两个来源生成候选，人工逐篇判定（297 篇）；系统检索到但不在候选中的再补判（118 篇，即 pooling）；② 参考要点：作者为 24 道范围内题写了 2–4 条要点 |
| 阅卷 | 大模型盲评：同一题的三份回答打乱顺序、隐去系统名，对照参考要点逐条判"覆盖 / 部分覆盖 / 未覆盖"，并核查每个引用是否被对应摘要支持 |
| 人工复核 | 随机抽 20 份回答（57 条要点判定），由作者独立判定，计算与阅卷模型的一致性 |

**指标**

| 指标 | 定义 |
|---|---|
| 检索 Precision@5 | 前 5 篇中人工判为相关的比例。很多题有几十篇相关文献，Recall@5 没有意义，所以用 Precision |
| 要点覆盖率 | （覆盖 + 0.5 × 部分覆盖）/ 要点数 |
| 引用支持率 | 被摘要支持的引用 / 全部引用（部分支持按 0.5） |
| 无效引用 | 引用的 PMID 不在本次检索结果中（代码检查，不依赖模型） |
| 拒答率 / 编造率 | 范围外题中，明确说明文献未涉及的比例 / 仍给出实质医学结论的比例 |

## 三、结果

### 范围内题（24 题）

| 系统 | 检索 P@5 | 要点覆盖率 | 引用支持率 | 无效引用 | 与要点矛盾的结论（每题） |
|---|---|---|---|---|---|
| A 纯大模型 | — | 59.9% | — | — | 0.17 |
| B 向量 RAG | 83.3% | **76.9%** | 98.3% | 1 | 0 |
| C GraphRAG | **85.8%** | 76.2% | 97.4% | 0 | 0 |

### 范围外题（6 题）

| 系统 | 拒答率 | 仍给出实质结论 |
|---|---|---|
| A 纯大模型 | 0% | 100% |
| B 向量 RAG | **100%** | **0%** |
| C GraphRAG | 83.3% | 16.7% |

### 按题型（要点覆盖率）

| 系统 | 药物比较 | 相互作用与药代 | 特殊人群 | 汇总 |
|---|---|---|---|---|
| A 纯大模型 | 48.6% | 75.0% | 61.1% | 54.9% |
| B 向量 RAG | 59.7% | 97.2% | 72.2% | 78.5% |
| C GraphRAG | 59.7% | 94.4% | 75.0% | 75.7% |

- 相互作用与药代类提升最大（75% → 97%）：这类问题的答案往往集中在一两篇药代研究里，检索到就能答对。
- 药物比较类三个系统都最低：这类题的要点常常需要综合多篇文献的结论（例如"多数研究显示……，个别研究相反"），只读 5 篇摘要难以覆盖。
- **汇总类本应是图谱最有优势的题型，但 C 并没有超过 B**，说明目前"把图谱统计放进提示词"的方式没有发挥作用。

### 按出题人（要点覆盖率）

| 系统 | 作者出题（10 题） | 图谱出题（14 题） |
|---|---|---|
| A 纯大模型 | 65.0% | 56.2% |
| B 向量 RAG | 80.8% | 74.1% |
| C GraphRAG | 80.8% | 72.9% |

图谱出的题得分反而更低，没有发现"从图谱出题导致 GraphRAG 得分虚高"的偏差。

### 人工复核

| | 阅卷模型 | 人工 |
|---|---|---|
| A 纯大模型（8 份） | 66.7% | 66.7% |
| B 向量 RAG（6 份） | 92.4% | 84.7% |
| C GraphRAG（6 份） | 88.9% | 86.1% |

57 条判定中 53 条一致（93%），κ = 0.85。4 处不一致全部是模型判"覆盖"、人工判"部分覆盖"（或模型判"部分覆盖"、人工判"未覆盖"），原因都是模型忽略了限定条件，例如"尤其阿哌沙班""个别研究中……"。阅卷模型对 RAG 回答略偏宽松，但不改变系统间的排序。

## 四、错误分析

| 问题 | 例子 | 说明 |
|---|---|---|
| **检索失败** | Q09"肝素和阿哌沙班相比，哪种出血风险更低" | 语料中有 46 篇相关文献，但 B、C 检索到的前 5 篇都是 DOAC 之间的比较。向量被"阿哌沙班"主导，"肝素"被稀释。系统随后回答"文献未涉及"：行为本身正确，问题出在检索 |
| **实体混淆** | Q27"丹参制剂和华法林合用"（范围外题），C 的回答 | 把**三七**总皂苷（*Panax notoginseng* saponins）当成丹参，基于两篇三七与华法林的临床前研究给出结论。引用的文献真实存在、引用检查也能通过，比凭空编造更隐蔽；B 在同一题上正确拒答 |
| **PMID 抄错** | Q14，B 的回答 | 引用了 PMID 3908021，正确的是 36908021（少了一位数字）。被代码的"无效引用"检查发现 |
| **纯大模型无法区分"知道"和"文献支持"** | 范围外 6 题 | A 全部给出了结论（例如圣约翰草诱导 CYP3A4、降低利伐沙班浓度）。这些结论在医学上大多是对的，但不来自本系统的文献库，用户无法核对出处 |

## 五、局限性

1. **样本量小**：30 题，每个题型 6 题，题型之间的差异只能作为参考。
2. **单人标注**：参考要点和相关性判定都由作者一人完成，没有第二位标注者。
3. **阅卷与回答是同一个模型**：可能偏好自己的写法。人工复核显示整体可信，但对 RAG 回答略偏宽松。
4. **候选文献依赖系统本身**：相关文献的候选一部分来自抽取结果。用关键词检索补充、对系统检索结果做 pooling 补判，减轻了但不能完全消除这一偏差。
5. **缓存使结果可复现，但只反映一次采样**：同一个问题模型每次回答会略有不同，本评估没有测量这种波动。

## 六、下一步

- **改进检索**：针对 Q09 这类失败，在向量检索的前 50 篇候选上加一层重排序（如 PubMed 专用的 MedCPT 模型），用本题库的 P@5 和要点覆盖率衡量效果。
- **重新定位图谱的作用**：问答中只在有直接证据时才使用图谱统计（避免诱导实体混淆）；图谱主要用于跨文献汇总、矛盾检测和说明书比对。
